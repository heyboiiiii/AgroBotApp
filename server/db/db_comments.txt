        Capabilities of this:

            Distance traveled:

            SELECT ST_Distance(
            point1.location,
            point2.location
            );

            Check if cow is inside a field:

            SELECT ST_Contains(
            yard.boundary,
            gps.location::geometry
            );

            Nearest cows:

            SELECT *
            FROM gps_positions
            ORDER BY location <-> some_point
            LIMIT 10;
