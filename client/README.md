AgroNomad App

Objectives:

*take info from  a socket (C scripts in the pi will send data) 

*Data received:

    GPS -> (LAT., LONG.) of each Agroneck

    ID -> Unique for each Agroneck

    Temperature

    Heart beat 

    Battery capacity


*Data displayed to User:

    Map -> with the position of all the Agronecks and the position of the AgroNeckServer.

    *The has to be able to press in the icon of the cow on the map, and it will open a tab where he will see the profile of the animal:

    1 - ID

    2 - Name asigned

    3 - Temperature 

    4 - Heart Beat
